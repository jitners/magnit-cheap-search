# Дешёвый Магнит

Небольшой сайт, который ищет товары в сети «Магнит» и помогает найти самые
дешёвые из них с привязкой к городу и конкретному магазину. Работает и локально
(PowerShell), и в облаке на Vercel.

## Что умеет

- поиск товаров по названию (например, «молоко», «сыр», «кофе»);
- просмотр всего ассортимента магазина от дешёвых к дорогим — без запроса и категории;
- выбор города (автодополнение по всей России);
- выбор конкретного магазина в городе (с фильтром по адресу);
- мини-карта магазинов города: точки кликабельны, выбранный магазин подсвечивается;
- цены именно выбранного магазина — в разных магазинах одного города они отличаются;
- сортировка: сначала дешёвые / дорогие, по скидке, популярности, рейтингу, новинкам;
- просмотр категорий магазина (молочные продукты, бакалея и т. д.): боковая панель с поиском
  и навигацией по разделам — все три уровня каталога, хлебные крошки и быстрый сброс;
- сравнение цен по магазинам города: сервис опрашивает несколько магазинов и показывает,
  где товар дешевле всего и сколько можно сэкономить;
- карточки товаров со старой ценой, процентом скидки, рейтингом, остатком и ценой за единицу;
- корзина: кнопка ★ на карточке сохраняет товар вместе с ценой, остатком и магазином;
  отдельная панель со списком, суммой, остатками и кнопкой «Проверить цены»;
  данные хранятся в браузере;
- переход на страницу товара на magnit.ru с сохранением выбранного магазина;

## Как запустить

Нужен только Windows и встроенный PowerShell — ничего устанавливать не надо.

1. Дважды кликните `start.bat`.
2. Откроется браузер с адресом `http://localhost:5080/`.
3. Выберите город, магазин, введите товар — готово.
   Чтобы увидеть весь ассортимент магазина от дешёвых к дорогим, оставьте поле поиска пустым
   и нажмите «Найти» (или кликните «все товары магазина» на стартовом экране).

Если порт 5080 занят, запустите с другим портом:

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1 -Port 5081
```

Чтобы не открывать браузер автоматически:

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1 -NoBrowser
```

Остановка сервера — `Ctrl + C` в окне консоли или закрытие окна.

## Как это устроено

```
server.ps1        локальный сервер: отдаёт страницу и проксирует запросы к magnit.ru
public/index.html разметка страницы
public/styles.css оформление
public/app.js     логика: города, магазины, поиск, сортировка, сравнение, карта
public/vendor/leaflet/  локальная копия Leaflet (карта работает без CDN)
lib/magnit.js     облачный порт серверной логики (Vercel, Node)
api/*.js          серверлесс-функции: /api/cities, /api/stores, /api/categories, /api/products
dev-server.js     локальный запуск облачной версии (node dev-server.js, порт 5090)
vercel.json       конфигурация деплоя на Vercel
start.bat         запуск в один клик
start-lan.bat     запуск с доступом из локальной сети (для телефона)
setup-lan.bat     разовая настройка доступа по Wi-Fi (запрашивает права администратора)
```

Магнит не отдаёт CORS-заголовки, поэтому браузер не может обращаться к его API напрямую —
запросы обязательно идут через серверную часть. Локально это делает `server.ps1`,
в облаке — функции из `api/` на Node.

### Деплой на Vercel

1. Загрузите репозиторий на GitHub (или выполните `vercel` из корня проекта).
2. В Vercel импортируйте репозиторий. Framework Preset — **Other**,
   Output Directory — `public`, функции из `api/` подхватятся автоматически.
3. После сборки сайт доступен на `https://<проект>.vercel.app`.

Проверить облачную версию локально: `node dev-server.js` и открыть `http://localhost:5090/`.


### Мини-карта магазинов

В поле «Магазин» есть кнопка «На карте»: она открывает карту города с точками магазинов.
Клик по точке выбирает этот магазин — поле адреса обновляется, а активный поиск сразу
пересчитывается под новый магазин. Выбранная точка увеличена и подсвечена красным.

- «Весь город» — показать все магазины города;
- «К выбранному» — приблизить к текущему магазину;
- «×» или повторное нажатие «Скрыть карту» — свернуть карту.

Координаты приходят из того же API магазинов. Сам Leaflet лежит в `public/vendor/leaflet/`,
а тайлы подгружаются с OpenStreetMap, поэтому для отображения подложки нужен интернет.
В режиме сравнения карта автоматически скрывается.

## Важно

- Проект неофициальный и не связан с АО «Тандер» / сетью «Магнит».
- Цены и наличие загружаются с публичного сайта magnit.ru и могут отличаться от кассы.
- Не используйте сервис для массовой нагрузки на сайт: сравнение ограничено
  10–40 магазинами и запускается вручную.
